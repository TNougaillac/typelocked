# Pokédex du jeu (TypeLocked)

Toutes les espèces d'Essentials v21.1 qui passent les règles du roster : 665 espèces, 310 familles, sur les 898 de `PBS/pokemon.txt` (les plugins n'ajoutent aucune espèce). Chaque monde en tire 300 au hasard, par familles entières (plugin ProceduralEncounters). Données brutes : [pokedex.csv](pokedex.csv).

## Règles

- **Exclus :** légendaires, fabuleux (Manaphy et Phione compris) et Ultra-Chimères. Formes régionales non comptées à part.
- **Variété d'attaques :** chaque famille retenue a au moins un membre à 5 ou plus (types d'attaques offensives hors type du run ; par niveau = 1, CT/tuteur seulement = 0,5). 32 familles sont écartées par cette règle (ex. Goupix, Otaria, Rosélia, Flabébé, Motisma, Zarbi).
- **Force** = total des stats de base de la forme finale : **faible** < 480, **moyen** 480 à 514, **fort** ≥ 515.
- **Types** comptés comme le plugin Monotype (une espèce compte aussi pour les types de ses évolutions).
