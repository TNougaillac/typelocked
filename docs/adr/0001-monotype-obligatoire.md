# Le Monotype est le mode principal, et le type imposé y est obligatoire

Dans le mode principal, le Monotype n'est pas un choix : chaque partie impose un type au joueur, et la fenêtre de début de partie ne propose que la difficulté (type tiré au hasard ou choisi). Le but du jeu est une expérience stratégique qui repose aussi sur la chance, et le type imposé en est le cœur ; un joueur qui lit « mode Monotype » ne doit pas « corriger » le plugin pour le rendre optionnel dans ce mode.

Mise à jour (novembre 2026) : un autre mode, sans type imposé, viendra plus tard. Il sera défini à ce moment-là, sans changer les règles du mode principal. En attendant, ce qui dépend du type imposé (comme les obstacles du Don du Pacte) est construit pour que ce futur mode puisse s'y brancher.
