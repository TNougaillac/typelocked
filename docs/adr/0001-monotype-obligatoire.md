# Le Monotype est obligatoire

Le mode Monotype n'est pas un choix : chaque partie impose un type au joueur, et la fenêtre de début de partie ne propose que la difficulté (type tiré au hasard ou choisi). Le but du jeu est une expérience stratégique qui repose aussi sur la chance, et le type imposé en est le cœur ; un joueur qui lit « mode Monotype » ne doit pas « corriger » le plugin pour le rendre optionnel.
