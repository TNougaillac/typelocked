# Noms de lieux tirés par la graine du monde (voir docs/LORE.md), lus par le
# générateur via la clé « Toponymie » de monde.txt. Ce fichier est hors du
# dossier des lieux, pour que la CI ne le prenne pas pour un plan de ville.
#
# [Formes] : comment un nom de base devient un nom de lieu. {nom} = un nom tiré
# dans une des autres sections ([Italien], [Americain], [Francais]...), à parts
# égales, jamais deux fois le même. Plusieurs formes séparées par « | » : une
# est tirée au hasard (française ou anglaise).
# - Village : la première ville et les villes sans arène ;
# - Port : les villes portuaires (au bord de la mer) et les cités lacustres ;
# - Ville : les autres villes ;
# - Grotte : les grottes des routes.
# Les routes sont numérotées (Route 1, Route 2...).
# [Region] : noms possibles pour la région entière (Carte de la région).

[Formes]
Village = Bourg {nom} | {nom} County
Port    = Port {nom} | {nom} Dock | {nom} Harbor
Ville   = {nom}ville | {nom} City
Grotte  = Grotte {nom} | {nom} Cave
